# HalfPullback v1.4

XAUUSDの押し目買い・戻り売りを検知するMT5インジケーターです。
今回の変更は、形成中の足で短時間だけ成立する即時サインを抑える待機機能です。
確定サインの判定、上位足、推進波・半値・包み足・ピンバーの条件はv1.3と同じです。
勝率・損益評価や自動売買は行いません。

## 設置

1. ZIP内の `.mq5`、3つの `.mqh`、`.ex5` を、MT5の「ファイル→データフォルダを開く→MQL5→Indicators」の同じフォルダーに置きます。
2. 旧バージョンをチャートから外し、v1.4を設置します。併用すると双方から通知されます。
3. スマホ通知はMT5の「ツール→オプション→通知」に設定します。テスターではPushは送信されません。

## 即時成立の連続観測

`InpInstantStablePercent` の初期値は **1.0（時間足の1％）** です。0～50を指定でき、0はv1.3相当の即時判定です。
必要秒数は端数を切り上げます。

| 時間足 | 1％での待機時間 |
|---|---:|
| M1 | 1秒 |
| M5 | 3秒 |
| M15 | 9秒 |
| H1 | 36秒 |
| H4 | 144秒 |
| D1 | 864秒 |

条件成立を最初に観測したティックから待機します。途中のティックで条件が崩れればリセットします。
待機が終わった後の最初のティックで、即時通知と矢印表示を行います。
待機中は矢印を表示しません。パネルのPA・成立表示は元の価格条件を表示するため、成立と表示されても通知待機中の場合があります。
パネル最下段の「待機中」は0＝なし、1＝買い、2＝売り、3＝両方向です。

一度即時通知した方向は、その足では追加の待機を課しません。崩れたら矢印を消して条件崩れを一度通知し、回復したら矢印を再表示します。
通知は同じ足・同じ方向につき「即時」1回、「条件崩れ」1回、「確定または確定不成立」1回までです。
確定通知は待機条件を適用せず、次の足の最初のティックで処理します。待機中のまま確定した場合も、確定サインは通知します。
即時通知前に消えた候補には条件崩れ・確定不成立のPushを送りません。

これはティックを観測するフィルターです。ティック間に価格がどう動いたかは判断できません。
時間経過だけでは処理せず、次のティックを待ちます。休場をまたぐ場合、確定通知は取引再開後になります。
時間足・設定の変更、再設置、端末再起動では待機・通知状態をリセットします。同じ足での履歴再取得では保持します。

## CSVで効果を確認

同じ期間・銘柄・時間足・ティックモデルでテスターを再実行してください。時間の待機を再現するため「実ティックに基づいた全ティック」を推奨します。
CSVは `HalfPullback_v1.4_...csv` です。保存先はMT5共通データフォルダーの `Files`：
`%APPDATA%\MetaQuotes\Terminal\Common\Files`

v1.3の44列に以下の5列を追加しました。

| 列 | 内容 |
|---|---|
| instant_stable_percent | 設定した待機割合 |
| instant_stable_seconds | 時間足から計算した必要秒数 |
| raw_seen_mask | その足で元の即時条件を観測した方向 |
| instant_sent_mask | 実際に即時通知した方向 |
| stability_wait_mask | 直近ティックで待機中だった方向 |

マスクは0＝なし、1＝買い、2＝売り、3＝両方向。初期履歴の3つのマスクは-1（観測なし）です。
「即時抑制」は元の条件を観測したものの即時通知に至らなかった足を、足の確定処理時に記録する監査専用イベントです。Push・ポップアップは送りません。
「即時抑制」と「確定」が同じ足にある場合、即時通知には至らず、確定サインのみ出たことを意味します。
終了時点で未確定の足の抑制結果は、次の足が来るまで記録されません。

まずH1・待機1％で、前回の即時125件、条件崩れ124件、確定16件、確定不成立109件と比較します。
確定16件の日時・方向・波が一致することと、即時・不成立通知の減少幅を確認します。
1％は初期の検証値で、実データで効果を確認した最適値ではありません。実際の減少件数は再テストまで未確認です。

元の検知仕様は同梱の `BASE_README_v1.3.md` を参照してください。そこに記載されたv1.3のファイル名・44列は旧仕様で、v1.4では本書が優先します。
